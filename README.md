# X 自动连播助手 (X Autoplay Extension)

一款专为 X (Twitter) 设计的 Chrome 浏览器扩展（Manifest V3），带来沉浸式自动连播刷帖体验。

## ✨ 主要功能

- **VITRA 极简微型悬浮按钮**：搭载 **VITRA UI** 极简光学材质与**胡克定律果冻弹性物理引擎**（支持拖拽拉伸与松手回弹，QQ 弹弹），极致小巧无干扰；彻底移除屏幕泛白的发光阴影，不破坏页面原生对比度。
- **个性化设置面板**：悬浮窗内置齿轮微按钮，点击即可呼出 VITRA 晶体毛玻璃设置面板；支持自由配置图片停留秒数、推文阅读秒数、短视频自动重播规则及判定阈值，并支持一键恢复作者推荐默认值。
- **全局快捷键与自定义录制**：默认设置右手最顺手、最好按的 `P` 键（Play/Pause），在网页任意位置一键开启或暂停连播（打字发帖时不触发）；支持在设置面板中点击按键框自定义录制为任意快捷键。
- **视频 X 原生大屏沉浸播放**：直连 **X 原生大屏**播放（可正常看评论、点赞、收藏），视频短于 5 秒自动连播两遍（可自定义秒数或关闭重播）；若遇到特殊视频则原地平滑播放，彻底去除冗余全屏幕布。
- **极简秒数徽章**：去除冗长提示文字，仅在倒计时时显示纯秒数微标（如 `5s`），倒计时结束后自动隐藏，始终保持微型小按钮形态。
- **图文自动浏览**：单图点开大图停留 5 秒，多图每 5 秒自动翻页，纯文字停留 4 秒；刷到底部自动加载新帖，无缝连播。
- **你的操作永远优先**：你随时可以自己滚动页面、手动翻图、拖动进度条、暂停视频或关掉大图，扩展都会顺着你的操作往下走，绝不会强行把你拉回原处。

## 🚀 安装方法（Chrome / Edge / Brave）

先把扩展下载到电脑上：在本页面右上方点绿色的 **Code** 按钮 → **Download ZIP**，下载后解压。然后：

1. 打开 Chrome 浏览器，在地址栏输入：
   ```
   chrome://extensions/
   ```
2. 在页面右上角打开 **“开发者模式”**（Developer mode）开关。
3. 点击左上角的 **“加载已解压的扩展程序”**（Load unpacked）。
4. 在文件选择窗口中，选中桌面的 `x-autoplay-ext` 文件夹并点击打开。
5. 打开 [https://x.com/](https://x.com/)，即可在页面左上角看到“▶️ 开启连播”悬浮按钮！
