# X 自动连播助手 (X Autoplay Extension)

一款专为 X (Twitter) 设计的 Chrome 浏览器扩展（Manifest V3），带来沉浸式自动连播刷帖体验。

## ✨ 主要功能

1. **半透明毛玻璃悬浮窗**
   - 网页左上角固定显示悬浮控制组件：“▶️ 开启连播 / ⏸ 暂停连播”。
   - 带有运行呼吸指示灯（绿色连播、橙色暂停）与实时状态显示（视频播放进度、图片倒计时等）。
   - **支持按住拖动**：可随意拖拽至屏幕任意位置，避免遮挡内容，自动记忆保存位置。

2. **智能视频全屏连播**
   - 默认用 **X 自带的大屏**播放视频：评论、点赞、收藏这些 X 原来的功能都能用。悬浮按钮上可以切换成"幕布"模式（只看视频）。
   - 找不到 X 大屏的时候，会自动改用幕布模式。
   - 遇到视频，在整个网页最上面盖一层黑色"幕布"，把视频画面铺满窗口播放。不改 X 自己的网页，所以页面不会乱跳。
   - **进度条可以点、可以拖**；← / → 后退 / 前进 5 秒。
   - **点画面**或按**空格**暂停/继续。
   - 全屏后**自动开声音**（X 默认是静音的）；按 **M** 关掉声音后，后面的视频也保持静音，再按一次 M 打开。
   - 右上角 **✕ 退出全屏**（或按 ESC）：只撤掉幕布，视频在原地接着播完再去下一条。**⏭ 下一条**（或按 N）：直接跳过这个视频。
   - 自动关闭循环播放（`loop = false`）；**短于 5 秒的视频会自动播两遍**。
   - 想连浏览器地址栏也盖住：先按 `Ctrl + Cmd + F` 让浏览器本身全屏，再开启连播（浏览器规定，真全屏只能你亲手开）。

3. **单图与多图全屏大图浏览**
   - **单图推文**：自动点开全屏大图（Lightbox 模式），停留 5 秒供欣赏，随后自动关闭并滚动到下一条。
   - **多图推文**：自动点开第一张全屏大图，每隔 5 秒自动点击“下一张”按钮（兼容键盘右箭头快捷键），浏览完最后一张大图后自动关闭弹窗，并平滑滚动到下一条帖子。

4. **纯文本与瀑布流加载**
   - 纯文字推文自动停留 4 秒供阅读。
   - 浏览到底部推文尽头时，自动平滑向下滚动触发 X 的流式数据加载，无缝持续连播。

5. **你的操作优先**
   - 你自己滚动页面：当前这条就算看过，等你停下来，从你眼前那条接着播，不会把你拉回去。
   - 你在大图里自己翻图：从你翻到的那张重新计时；你自己关掉大图：直接去下一条，不会再打开。
   - 你自己暂停的视频不会被自动播放；你自己去了别的页面：连播自动暂停，不会把你拉回来。
   - 暂停后再开启，从屏幕上眼前这条重新开始。

## 🚀 安装方法（Chrome / Edge / Brave）

先把扩展下载到电脑上：在本页面右上方点绿色的 **Code** 按钮 → **Download ZIP**，下载后解压。然后：

1. 打开 Chrome 浏览器，在地址栏输入：
   ```
   chrome://extensions/
   ```
2. 在页面右上角打开 **“开发者模式”**（Developer mode）开关。
3. 点击左上角的 **“加载已解压的扩展程序”**（Load unpacked）。
4. 在文件选择窗口中，选中桌面的 `x-autoplay-ext` 文件夹并点击打开。
5. 打开 [https://x.com/](https://x.com/)，即可在页面左上角看到“▶️ 开启连播”悬浮按钮！
